## SkillMatch JS: Simulador de Compatibilidade com Vaga Front-End Júnior

## Descrição do projeto

Com o aumento de candidaturas para vagas de tecnologia, houve a necessidade de criar um sistema que automatize a compatibilidade de um candidato com as vagas selecionadas.
O projeto em questão visa realizar esta pré-triagem para auxiliar tanto os setores de RH das empresas, como também ao candidato, retornando para o mesmo as vagas que possui maior compatibilidade, junto com uma recomendação de estudo para assuntos que tem pouca afinidade.

## Objetos e funções criadas

As classes criadas foram: Candidato, Vaga e CandidatoVaga.

O código engloba as seguintes funções:

- Calcular compatibilidade do candidato com a vaga;
- Filtrar os requisitos encontrados;
- Filtrar os requisitos que não foram atendidos;
- Retornar a vaga mais compatível com o candidato;
- E por fim irá informar uma recomendação de estudo com as habilidades que o candidato deve aperfeiçoar.

No final mostrará um resumo com todas as informações citadas acima.

## Como executar

Para executar este miniprojeto, será necessário apenas um navegador de internet:

1. Abra o console do navegador: Google Chrome, apertando F12, ou Opera GX, apertando Ctrl + Shift + I;
2. Vá para a aba console;
3. Copie o código que esta no skillmatch.js;
4. Pressione o botão Enter.
